# 设计实现、响应式与质量底线

## 设计来源与还原

优先级：已确认设计系统和设计稿 → PRD 的品牌、用户和场景 → 已确认参考产品 → 合法可用的第三方设计系统 → 中性默认。

- 有 Figma 或等价设计稿时，使用环境中可用的设计读取流程检查目标节点、关键子层和截图；不要只凭记忆或大图猜细节。
- 核对结构、尺寸、间距、字体、字重、颜色、圆角、阴影、图标、图片、组件状态和响应式意图。
- 临时设计资源 URL 可能过期；长期交付前下载并提交有权使用的真实资产，检查请求与页面渲染成功。
- 参考产品的受保护资产不能直接复制。开源或可商用设计系统可以按许可使用 token；其他来源只借鉴可泛化的视觉语言。
- 第三方参考站可先读取公开的 DESIGN.md、token 或文档；登录、反爬或纯 SPA 阻塞时，请用户提供关键截图与文本，而不是猜。
- 没有设计稿时，先明确颜色、字体、密度、圆角、页面结构和关键组件，做一个代表页使方向可见，再铺开全站。

## 最低设计系统

即使 MVP 也统一：

- 主色、背景、表面、文本、边框、成功、警告、危险和信息色；
- 字号层级、字重、行高与长文本宽度；
- 4 或 8 像素间距节奏；
- 圆角、边框和阴影层级；
- 页面最大宽度与内容密度；
- Button、Input、Select、Card、Dialog、Toast、Badge；
- hover、focus-visible、active、disabled、loading、error。

Tailwind 负责布局和原子样式，CSS 变量或 Tailwind theme 表达语义 token。避免无含义色值和尺寸在页面中散落；也不要把 Tailwind 本身当成设计系统。

## 中文字体

- 商业西文字体通常不含中文字形，不要擅自打包或假设它能覆盖中文。
- 可用合法免费西文字体配合中文系统回退：PingFang SC、Microsoft YaHei、Noto Sans CJK SC 等。
- `next/font` 的字体在构建时自托管，不等于运行时请求外部 CDN；仍需确认授权和中文字形回退。
- 可以保留正文与展示标题的双字体层级，但中文回退必须统一，避免同页字形混乱。
- 在真实浏览器检查计算后的字体和字重，不只看 CSS 声明。

## 组件层级

- 基础：Button、Input、Select、Dialog；
- 复合：FileUploader、TaskStatus、ArtifactPreview；
- 业务：面向一个具体任务的表单或运行面板；
- 页面：组织布局和用户流程，不堆积所有底层细节。

优先复用项目已有组件；再用语义 HTML 和轻量自建组件；复杂交互用成熟无障碍基础组件。只有重复模式真实出现后才抽象，避免十几个参数的“万能组件”。

图标统一一个家族，不用 emoji 代替正式功能图标。仅图标按钮有可访问名称和悬停说明。按钮用动作与结果命名，状态文案用产品语言。

## 响应式验收

PRD 未另行指定时至少检查：390、768、1280、1440 CSS 像素宽度。核心流程的每个页面、弹窗和关键状态都要检查，不只首页。

- 桌面侧栏在手机变成抽屉或底部导航；关闭后不残留透明遮罩。
- 弹窗在小屏可滚动，主操作始终可触达。
- 表格转卡片、分组或受控横向滚动，不简单缩小字体。
- 固定宽度媒体不撑破屏幕；页面无意外横向滚动。
- 触控目标建议至少 44×44px。
- 移动键盘弹出时输入和提交仍可触达。
- CSS 响应式状态与 React 状态一致，旋转和窗口缩放后不出现假展开或遮挡。

不要通过给整个应用加 `zoom` 或 `transform: scale()` 来“适配”设计尺寸；保持组件原始设计尺度，由布局、断点和容器响应真实视口。

## 无障碍基础

- 使用语义 HTML，表单控件关联 Label。
- 核心操作可键盘完成，焦点清晰；Dialog 限制焦点并在关闭后正确返回。
- 状态不只依赖颜色；文字与背景有足够对比。
- 图片使用恰当替代文本，装饰图标不重复朗读。
- 尊重 `prefers-reduced-motion`。
- Agent 关键进度可使用节制的 live region，不逐 Token 朗读。
- 错误可被辅助技术识别并关联到字段。

## 安全与隐私

- 模型 Key、数据库密钥、服务私钥、私密系统 Prompt、管理员凭证和只应服务端掌握的规则不进前端。
- Web 鉴权优先安全、HttpOnly、合理 SameSite Cookie；避免长期令牌放 Local Storage。
- 同时考虑 CSRF、XSS、会话过期和跨设备退出；前端隐藏不等于权限控制。
- 用户或模型生成的 HTML 默认不可信；Markdown 限制危险标签和链接，外链设置安全属性。
- 文件名、富文本和 URL 不直接拼入 DOM。
- 日志、埋点和报错不上传完整 Prompt、隐私文件、生成内容或凭证。
- 扣费、发布、群发、删除、覆盖和外部写入前展示影响并最终确认；后端再次校验权限和幂等，保留结果或审计入口。

## 性能与可观察性

- 先测量再优化；当前页不用的大型库不进首屏，编辑器、图表和媒体工具按需加载。
- 图片选择适当尺寸、格式和懒加载，媒体预留比例，减少布局跳动。
- 大列表分页或在真实需要时虚拟化；流式内容节流或批量更新。
- 避免多个组件重复请求；大型二进制不长期放 React State。
- MVP 不要求性能分数满分，但明显卡顿、内存泄漏和冻结不能以“以后优化”略过。

前端错误至少关联时间、页面、功能、错误码、请求或任务 ID、应用版本和是否可恢复。埋点只有 PRD 或指标方案明确且合规时才实施；埋点失败不得阻塞核心任务。
