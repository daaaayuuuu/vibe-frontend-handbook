# 自动检查、真实浏览器验收与交付

## 最低自动检查

每个可交付阶段执行项目已有的等价脚本，默认至少：

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

如果缺少合理的最低脚本，按现有栈补齐或说明等价命令，例如 `tsc --noEmit`。不能无说明写“跳过”。

测试分层：

| 层级 | 重点 |
| --- | --- |
| 单元 | 状态映射、转换、运行时校验、错误归一化、去重 |
| 组件 | 表单、按钮、加载/空/错、确认、取消与可访问性 |
| 集成 | API 或流适配层与页面流程 |
| E2E | 从进入页面到得到真实结果并刷新恢复的核心闭环 |
| 人工预览 | 视觉、文案、媒体、响应式、权限和浏览器行为 |

Mock 可覆盖确定性 UI 和错误分支，但最终联调必须使用真实后端。仅按钮可点击或 Mock 产物可见不算业务闭环。

## 核心闭环基线

每阶段至少完成一条可重复操作链路：进入页面 → 填写输入 → 成功提交 → 看到后端任务状态 → 处理用户确认（如有）→ 得到真实产物 → 刷新后恢复。

若后端能力或凭据尚未就绪，如实标记“真实联调待验”，说明已完成的 Mock 范围，不声称前后端完成。

## 真实浏览器验收

启动真实项目后，先确认服务器监听、URL、标题、品牌、路由和目标内容对应当前项目，防止相邻或缓存项目占用端口。HTTP 200 只证明有响应，不证明页面正确。

### 页面和业务

- 入口可访问，核心链路使用真实接口；
- loading、empty、failed、permission denied、not found 分开；
- submitting、queued、running、streaming、waiting_user、部分成功、成功、取消、断线与过期状态表现正确；
- 失败保留输入与已完成结果，重试影响明确；
- 连点不会创建重复任务或重复费用；
- 刷新、返回和重新登录后可按任务 ID 恢复；
- 产物能真实预览和下载，失效 URL 与加载失败有处理。

### 浏览器技术检查

- Console 无持续错误和未解释警告；
- Network 无失败、意外重复请求或永不停止的轮询；
- 流式内容真实逐段到达并可正确收尾、取消和重连；
- 浏览器前进后退和可分享 URL 恢复正确位置；
- 图片、SVG、字体、视频、音频和下载资源实际成功；
- 页面没有不可达控件、透明遮罩、焦点陷阱或无意横向滚动。

### 尺寸与输入方式

PRD 未指定时验证 390、768、1280、1440 宽度。检查核心流程每个页面、弹窗、侧栏、菜单和产物，不只首页。测试鼠标、键盘、触控目标和移动键盘。语音、麦克风、摄像头等能力在真实手机和 HTTPS 或 localhost 环境验证。

若使用浏览器自动化，截图只是证据之一；还要检查可交互状态、Console、Network、DOM/可访问名称、计算样式和溢出。自动检查与人工视觉判断互补。

## 不得宣布完成的情况

- lint、类型、测试或构建仍有未解释错误；
- 核心接口还是 Mock；
- 目标宽度下核心页面不可用；
- 失败会丢输入或刷新不能恢复运行任务；
- 重复提交会创建多个任务；
- Console 持续报错；
- 与已确认 PRD 或设计明显不一致；
- 只验证 HTTP、构建或静态截图，没有真实浏览器交互。

阶段性带问题交付必须列出问题、影响、临时处理与后续计划，并由产品负责人明确接受。

## 产品经理验收清单

将以下内容转换为当前产品的“打开哪里、点击什么、看到什么”的短清单：

- 是否能从入口一直得到一个真实结果；
- 当前步骤、等待原因、用户动作和下一步是否清楚；
- 失败、断网和刷新后是否能恢复；
- 重复点击是否重复创建任务或扣费；
- 手机和电脑能否完成同一核心流程；
- 侧栏、弹窗、菜单、媒体和下载是否真实可用；
- 运行、等待确认、部分成功、失败和完成是否清晰不同；
- 最终结果与中间过程是否分层；
- 自动检查、真实后端和浏览器验收结果是否透明。

## 与部署阶段的边界

本 Skill 只做前端发布准备，不因“前端开发完成”自动部署。用户明确要求部署时，再按目标平台方案执行。

Next.js standalone 发布前注意：

- `output: "standalone"` 只生成最小运行时，不上传完整 `node_modules`；
- `.next/static` 与 `public` 可能需要复制进 standalone 产物；
- rewrites 的后端地址可能在构建时固化，必须在构建阶段注入正确环境变量并实际验证；
- standalone 使用 `node server.js`，默认 3000；
- 前后端通常是两个独立部署应用，可通过同源 `/api/*` 代理减少 CORS；
- 麦克风、摄像头和剪贴板等线上能力要求 HTTPS。

具体命令、云资源、域名、Secret、灰度和回滚由部署方案决定，不能机械照搬。
